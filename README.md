# NCSM-Volunteer-Management-System
A web-based volunteer management system built with PHP, Laravel, and MySQL.
## Features
- **Admin Panel:** Manage volunteer accounts, view analytics, and control system settings.
- **Member Portal:** Profile management and activity tracking.
- **Feedback & Donations:** Public feedback submission and structured donation records.

## Tech Stack
- **Backend:** PHP, Laravel Framework
- **Database:** MySQL
- **Frontend:** HTML, CSS, JavaScript, Blade Templates
